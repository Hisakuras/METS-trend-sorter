# METS-SI 验证状态声明

本次修订遵循“可核验优先”原则。

## 已完成并有数值结果的内容

- 基于 statsmodels 内置数据集的真实数据补充实验；
- macrodata、danish、Grunfeld、El Niño、sunspots 和 CO₂ 的排序比较；
- OLS 与局部 Theil–Sen 斜率集合的 Spearman/Kendall 比较；
- 结构区间宽度的计算与结果表；
- 对丹麦和 Grunfeld 数据上局部中心失效的如实报告。

这些结果不被解释为真实数据上的绝对地面真值，因为真实序列没有已知真实斜率；Theil–Sen 只作为稳健参考排序。

## 尚未完成、不得写成已验证结论的内容

- NAB 的完整异常预警分数；
- NASA C-MAPSS 的发动机退化 Top-K 命中率；
- NASA PCoE 电池数据的寿命风险召回率；
- UCI 家庭用电数据的业务事件命中率；
- moving-block bootstrap 的真实覆盖率；
- 真实工业部署中的误报成本、漏报成本和人工复核收益。

这些数据集目前已经被纳入论文的应用验证设计和来源矩阵，但在完成原始数据下载、固定参数、时间切分、运行脚本和结果审计前，不应声称 METS-SI 在这些业务上已经优于其他方法。

## 复现要求

后续结果必须同时提交：

1. 原始数据来源和版本；
2. 下载或预处理脚本；
3. 固定参数和随机种子；
4. 时间切分方式；
5. OLS、Theil–Sen、METS、METS-SI 的完整结果；
6. 失败案例和限制；
7. 对真实标签缺失数据的标签构造规则。

该声明用于防止将研究设想、实验设计和已完成实验混为一谈。
